# Nguyễn Hữu Huỳnh Duy — Portfolio

A bilingual Vietnamese/English personal portfolio built with Next.js.

## Run locally
1. Install Node.js (LTS) from https://nodejs.org/
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open http://localhost:3000

## Deploy to Vercel
1. Push this folder to a GitHub repository.
2. Sign in to https://vercel.com/ with GitHub.
3. Choose Add New → Project, import the repository, then Deploy.

## Before publishing
- Replace the initials portrait placeholder in `app/page.tsx` with your approved portrait.
- Review the bilingual text and project descriptions.
- Add LinkedIn/social links if desired.
